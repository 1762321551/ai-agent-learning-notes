# 第八章实验 8-1：从零训练寻宝 Q-learning

执行日期：2026-10-09。[原环境与算法](https://github.com/bojieli/ai-agent-book/tree/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/chapter1/learning-from-experience)。代码目录在第一章，实验归属于第八章。

**已用原环境与原 Q-learning 实际完成训练及评估。** 三个预先固定随机种子各训练10000局，共30000训练episodes；训练前、训练后各100局。没有模型API，没有LLM微调；发生参数更新的是Q表。

## 方案与可复核操作

使用确定性寻宝环境。学习率0.2、折扣0.99、epsilon初值1、每局乘0.9995、最低0.1，使用原实现默认超参数，不更改奖励、地图或最优策略。种子固定为7、42、20261009；同时设置Python random和NumPy随机种子。

先评估未训练Q表，然后重置随机流并训练；每1000局记录最近1000局胜率。评估设置epsilon=0，不更新Q值。保存完整Q表、逐局奖励与长度、曲线、首局贪婪行动和源码hash。对完整世界状态独立执行BFS，证明该原地图存在11步最短路径；用保存Q表重放，核对记录与真实环境一致。

## 独立验证与限制

六项执行检查通过：三个seed齐备、训练数足够、评估数足够、评估Q值不变、轨迹与评估结果一致、成功路径不短于BFS最优值。独立复核重新加载保存的Q表，各重放100局并重新搜索最短路径，结果一致。

这是一张固定确定性地图；100局贪婪评估重复同一任务，不能当作100个独立任务或真实世界泛化证明。没有测试规则变化、随机环境、其他地图、LLM少样本对照、SFT、RLHF或模型权重更新。三seed结果也不是稳健统计研究。

对我最直接的帮助是理解“经验改变下一次行动”有不同载体：这里每一步奖励直接更新Q(s,a)；我们的库存Agent把历史交回模型，不会因此自动改模型权重。样本效率、计算成本、环境交互成本也需要分别比较。
